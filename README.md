# Hotline My Zombie / Dead Signal

Compiled browser edition. Clear three waves of zombies and reach extraction.

Enter starts. WASD or arrows move; the mouse aims; left click fires; Space or right click attacks. P or Escape pauses, H opens help, R restarts, Q returns to the title, and M toggles sound. A modern WebGL browser is required.

Only the sound preference is saved locally. Mission progress and scores reset on reload.

This repository contains the compiled game and runtime assets. Phaser licensing is in THIRD-PARTY-NOTICES.txt and licenses/Phaser-LICENSE.md. Pixel artwork, bitmap font and synthesized sound are original game assets.

The packaged build passed automated simulation, navigation and browser checks. Human balance and gameplay review remain unverified.
